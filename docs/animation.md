# 棋盘动画

导入 PGN 后点击播放或「重播这一手」。暂停后可拖动时间尺前后定位，使用 `,` / `.` 逐帧查看；定位和逐帧不播放音效。

## 编辑动画

选中棋盘上的棋子，或时间线中的片段，在属性面板修改坐标、缩放、旋转、透明度和关键帧。支持线性、保持及贝塞尔缓动，修改可撤销，预览与视频导出共用相同动画数据。

「移动预设」可应用到所选动作或该棋子的全部走子；之后仍可继续编辑。选中 NAG 入场／退场片段，可分别设置效果和粒子，再按动画部件编辑关键帧。

片段移动、拉伸、复制和删除在时间线上完成；锁定轨道后禁止编辑，隐藏画面轨道或静音音轨会同时影响预览与导出。

## 镜头与声音

「棋盘预览」用于选子和编辑，青色取景框表示镜头拍摄范围；「镜头预览」显示实际成片画面。通过「面板 → 独立镜头预览」可在系统窗口中查看，播放和定位与主窗口同步。

在「镜头与卡点」中编辑平移、缩放、旋转、对焦和震动。导入音乐后可检测、增删或修正节拍；按 B 在播放头添加节拍，再点击「自动卡点」应用。

音乐和音效片段可独立移动、裁剪、调节音量及淡入淡出。素材替换、关键帧、镜头和声音会随工程保存；桌面素材需要与同名 `.assets` 目录一起保留。

成片输出见 [视频导出](video-export.md)。
